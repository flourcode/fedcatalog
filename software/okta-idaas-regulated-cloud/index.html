What it does

The Okta IDaaS Regulated Cloud service offering provides centralized identity and access management capabilities to customers who want to manage access across any application or device, whether they are on-premise in the customer's office/data center or in the cloud. The Okta IDaaS Regulated Cloud service provides several important capabilities, including: - Okta Identity Engine (OIE) - Okta Multi-factor authentication (MFA) - Okta Adaptive MFA (AMFA) - Okta Single Sign-On (SSO) - Okta Verify - Okta API Integration - Okta FastPass - NIST 800-63B AAL2/AAL3 authenticator
