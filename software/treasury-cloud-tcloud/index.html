What it does

The Treasury Cloud High (TCloud-H) system is owned and operated by the Department of the Treasury, serving as a multi-cloud IaaS/PaaS hosting environment designed to process High Impact level information. It includes the following multitenant, government-exclusive cloud platforms: • Amazon Web Services (AWS) GovCloud East/West, • Oracle Cloud Infrastructure (OCI) GovCloud East/West, • Microsoft Azure GovCloud East/West, and • Google Cloud Platform (GCP) GovCloud East4/Central1 TCloud-H FedRAMP’ed environment is offered as a shared service to Treasury Bureau’s, available in two cloud hosting models: Boundary Protected and Managed.
