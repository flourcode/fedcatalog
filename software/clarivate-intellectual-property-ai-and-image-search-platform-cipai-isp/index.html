What it does

The Clarivate Intellectual Property AI & Image Search Platform (CIPAI-ISP) is a search engine of Clarivate’s intellectual property datasets (such as designs, patents, trademarks). Users can search by uploading an image or text as query into the web search interface. Matched results are returned and displayed in the user interface for users to analyze and generate reports. CIPAI-ISP is delivered via SaaS. It is hosted in AWS GovCloud. It is available to federal, state, local, and tribal governments, as well as federal contractors, government contractors.
