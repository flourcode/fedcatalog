What it does

The AMPS system boundary is a General Support System (GSS) that is made up of operating systems (OS) and services designed to run on third-party cloud hosting platforms. The purpose of this system is to allow USDA customers to leverage the robust capabilities of a FedRAMP cloud service provider (CSP) hosting environment for application delivery while DISC maintains the full management of the OS and services required to meet DISC controls at the High baseline level. The FedRAMP’ed CSPs are outside of the security boundary and AMPS inherits controls from the CSP. The AMPS system is a major part of DISC’s cloud service offering for applications external to DISC.
