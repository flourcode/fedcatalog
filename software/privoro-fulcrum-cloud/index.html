What it does

The Privoro Fulcrum Cloud (PFC) supports the use of and enhances the security of mobile devices in the Federal Government. Specifically, the PFC provides management and monitoring services for Privoro SafeCases (SC), which are out of boundary mobile security products that communicate to the PFC via the in boundary Privoro Mobile App (Privoro App) available for both iOS and Android. PFC and SafeCases support use cases such as mobile phone usage in Secure Spaces, mobile Signature Management and mobile Secure Comms.
