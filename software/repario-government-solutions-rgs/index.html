What it does

The Repario Government Solutions (RGS) system is of the type “software as a service (SaaS)”. The system is located in the Amazon Web Services, FedRAMP High authorized Gov cloud. The environment consists of windows virtual servers, serving as web, database application, continuous monitoring and encrypted storage servers
